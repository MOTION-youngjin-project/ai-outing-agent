# 메인 시간별 날씨 상세

메인 화면 오른쪽 위 날씨 배지를 버튼으로 바꾸고, 누르면 앞으로 최대 12시간의 온도·날씨·강수확률을 가로 목록으로 표시한다.

기상청 단기예보 API는 기존 호출 한 번에 시간별 항목을 최대 1,000개 받고 있었다. 이전 구현은 가장 가까운 시각만 남겼지만, 이번 변경은 같은 응답에서 12시간을 추려 같은 수집 시각으로 DB에 저장한다. 상세 패널을 열 때 외부 API를 추가 호출하지 않는다.

기존 단일 예보 캐시가 남아 있으면 현재 날씨는 그대로 표시하고 시간별 목록은 비어 있을 수 있다. 새 발표 주기가 시작되어 예보가 한 번 갱신된 뒤부터 12시간 목록이 표시된다.
