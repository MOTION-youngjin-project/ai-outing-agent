# T맵 데이터 API — 무료/유료 및 전국 주차장 데이터 존재 여부 조사

조사일: 2026-09-08
조사 목적: 지도교수 방향(대구 나들이 앱으로 먼저 완성 후 지역 확장)에 따라, 현재 유일하게 지역 제한이 있는 데이터 소스(대구광역시 통합주차정보시스템)를 T맵 데이터로 전국구화할 수 있는지 확인.

**조사 방식 참고**: 이번 조사는 백그라운드 서브에이전트(fork) 2회 시도가 전부 도구 호출 0회로 빈 결과만 반환해서(세션 이상으로 추정), 메인 세션에서 직접 WebFetch/WebSearch로 확인함.

---

## 1. 포털 신원

`openapi.sk.com`은 SK의 공식 오픈API 포털("SK open API")이며, 2026년 10월부터 "A.Console"로 명칭 변경 예정(공식 페이지 verbatim 확인). T맵 API 자체 문서는 `tmapapi.tmapmobility.com`(구 `tmapapi.sktelecom.com`, 접속 실패해서 새 도메인으로 확인)에 있음.

## 2. 제공 API 목록 (T맵 API 공식 문서, verbatim 확인)

- POI 검색
- 지오코딩
- 지오펜싱
- 교통정보
- 경로안내
- 다중 경유지안내
- 경유지 최적화
- Road API
- StaticMap
- what3words 주소 조회

**주차장(Parking) 관련 API는 이 목록에 없음.** 공식 문서에 명시된 API 종류 어디에도 주차장 위치/요금/실시간 잔여대수를 다루는 상품이 없다.

검색 중 발견된 "티맵 주차"(`tmapmobility.com/service/drive/parking`)는 **개발자용 API가 아니라 티맵 앱 자체의 소비자용 주차 예약/결제 서비스**로 보인다(제휴 주차장 예약 기능) — 데이터를 가져다 쓸 수 있는 오픈API가 아니다. 이 페이지 자체를 깊이 열람하지는 못해서 100% 단정은 아니지만, 공식 API 문서 목록에 없다는 사실만으로도 개발자가 쓸 수 있는 데이터 상품이 아닐 가능성이 매우 높다.

## 3. 요금제 (T맵 API 공식 문서, verbatim 확인)

- **무료 사용**: API별로 하루 무료 한도 존재 (예: "POI 검색 일 2만 건, 경로탐색 일 1천 건")
- **종량제(유료)**: 무료 한도 초과 시 API 호출량만큼 후불 과금
- **정액제(유료)**: **월 2,000,000원**(VAT 별도) — 사용량이 많거나 월별 편차가 클 때 권장

즉 **완전 무료가 아니다** — "무료 티어 + 초과 시 유료(종량제 또는 월 200만원 정액제)" 구조다. 공공데이터포털(TourAPI 등)의 "무료, 하루 N건 고정 한도"와는 결이 다르고, 상용 서비스에 가까운 과금 모델이다.

## 4. 인증/사업자 요건

이번 조사에서 회원가입/API 키 발급 페이지의 사업자 요건까지는 확인하지 못함(**미검증**) — `openapi.sk.com` 가입 절차를 실제로 밟아봐야 확정 가능.

## 5. 비교: 공공데이터포털에 전국 주차장 표준데이터가 있는지

이번 조사에서 data.go.kr을 직접 검색해 확인하지는 못함(**미검증**) — 다만 "전국 주차장 정보 표준데이터"라는 이름의 데이터셋이 지자체별로 각각 등록된 형태로(이 프로젝트가 이미 쓰는 대구광역시 API처럼) 존재하는 것으로 널리 알려져 있다(비공식 확인, 이 문서에서 1차 출처로 검증한 사실은 아님). 즉 "하나의 API로 전국 커버"가 아니라 "지자체마다 API가 따로 있고 형식은 표준화돼 있다"는 구조일 가능성이 높다 — 이것도 다음 조사에서 1차 출처로 확정 필요.

---

## 결론

1. **T맵 데이터는 무료가 아니다.** API별 일일 무료 한도가 있고, 초과하면 종량제 또는 월 200만원 정액제로 넘어가는 상용 과금 모델이다.
2. **주차장 데이터 자체가 T맵 API 공식 상품 목록에 없다.** "전국 주차장 데이터를 바로 쓸 수 있을 것"이라는 기대는 현재 확인된 사실과 다르다 — 애초에 그런 상품이 없어 보인다.
3. **이 학생 프로젝트 규모에서 지금 당장 쓸 현실적 선택지가 아니다.** 무료 한도가 있다지만 그 안에 주차장 데이터가 없으므로 이번 목적(전국 주차장 데이터 확보)에는 애초에 맞지 않고, 설령 다른 용도(경로안내 등)로 쓰더라도 유료 전환 문턱이 학생 프로젝트에는 부담스러운 수준(월 200만원)이다.

## 권장 사항

- 전국 주차장 데이터가 필요해지는 시점(지역 확장 단계)이 오면, T맵이 아니라 **공공데이터포털에서 각 지자체가 등록한 주차장 표준데이터를 지역별로 하나씩 추가하는 방향**이 이 프로젝트의 기존 패턴(대구광역시 API를 쓰는 것과 동일한 방식)과 일관되고 비용도 무료다. 다만 이건 이번 조사에서 확정 검증은 못 했으니, 실제 지역 확장을 시작할 때 다시 1차 출처로 확인할 것.
- 지금 단계(대구 나들이 앱 완성)에서는 T맵 API를 검토할 이유가 없다.

## 추가 조사 (2026-09-09) — 공공데이터포털 전국 커버 방안 확정

위 "권장 사항"에서 "확정 검증 못 함"으로 남겨뒀던 두 가지를 확인했다. 결론: **지자체별로 하나씩
신청할 필요 없이, 아래 국가 표준 API 2개만 신청하면 전국이 커버된다.**

1. **시설 기본정보 — 전국주차장정보표준데이터**
   (https://www.data.go.kr/data/15012896/standard.do)
   - **250개 제공기관**(지자체) 참여, 대구도 이미 포함된 국가 표준 스키마.
   - 이름/주소/총 구획수/운영시간/요금 등 정적 정보. 파일 다운로드(XLS/XML/JSON/RDF/CSV, 5만 건
     제한)와 **오픈 API 둘 다** 같은 페이지에서 제공(전체 데이터가 필요하면 API 사용 안내).
   - 무료.

2. **실시간 잔여 주차면수 — 한국교통안전공단_주차정보 제공 API**
   (https://www.data.go.kr/data/15099883/openapi.do)
   - 전국 대상(공간범위 지정 없음), 무료.
   - 일일 한도: 개발계정 10,000건, 운영계정은 활용사례 등록 후 증량 가능.
   - 주차장명/주소/위경도/총구획수/운영정보/실시간 잔여정보 제공.
   - **단, 페이지 자체에 "실시간 주차정보는 시설정보에 비해 정보의 수가 적음"이라고 명시** — 즉
     전국 주차장 전체가 실시간 잔여대수를 제공하는 게 아니라 일부만 제공한다(대구도 이미 마찬가지:
     이번 세션에 확인한 실제 응답에서도 상당수 주차장이 "총구획수"만 있고 "잔여대수"는 "-"로 비어있었음).
   - 두 API는 "주차장관리번호"로 매칭해서 연동해야 한다(실시간 API가 주소를 직접 안 줌).

**"어느 지역이 되는지" 리스트를 못 뽑은 이유**: 공공데이터포털 메타데이터 어디에도 "이 지자체는
실시간 제공, 저 지자체는 미제공" 같은 지역별 커버리지 표가 공개돼 있지 않다. 실시간 API 응답
자체(관리번호 단위)를 받아봐야 어느 주차장이 실제로 잔여대수를 주는지 알 수 있다 — 이건 신청·승인
후에 데이터를 실제로 당겨봐야 확정되는 부분이라, 신청 전 단계에서 지역별 목록화가 원천적으로 불가능
했다.

**신청 자격**: 두 페이지 모두 사업자등록 요건은 명시돼 있지 않음(개인/학생 신청 가능한 통상적인
공공데이터포털 오픈API와 동일한 절차로 보임 — data.go.kr 회원가입 → 활용신청 → 심의승인 → 인증키
발급). 승인에 며칠 걸릴 수 있으니 신청은 최대한 미리 해두는 게 좋다.

**적용 시 참고**: `src/lib/tools/parking.ts`가 이미 대구용으로 하는 것과 같은 패턴(district enum
+ 지역별 요청)을 전국 버전으로 일반화하려면, 이 두 API 데이터를 합쳐 `regions` 테이블의 시/도 단위로
매핑하는 작업이 필요하다 — 이건 API 키 발급 이후, 실제 응답 스키마를 보고 나서 설계할 것.

## 조사 한계 (투명성 고지)

- 백그라운드 서브에이전트 2회 시도가 모두 실패해서(도구 호출 0회) 메인 세션에서 직접 조사함 — 시간 제약상 T맵 API 회원가입/사업자 요건, "티맵 주차" 서비스의 정확한 성격(개발자 접근 가능 여부), 공공데이터포털의 전국 주차장 표준데이터 존재 여부는 확정하지 못했다(전부 "미검증"으로 표시).
- `tmapapi.sktelecom.com`은 접속 실패(ECONNREFUSED)해서 새 도메인(`tmapapi.tmapmobility.com`)으로 확인함 — 리다이렉트/도메인 이전 상황일 수 있음.
