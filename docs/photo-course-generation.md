# 12단계 포토 코스 생성

2026-09-17. D:/motion-parking-photo, feature/parking-photo-course. 기존 D:/motion 작업 및 운영 DB 보존.

## 구현

- /photo에서 확정한 취향 → 제목/방문 날짜/한국 시간 출발 시각/30~720분/도보·자동차·대중교통/출발 장소 → POST /api/photo-courses → 시간표/촬영 팁/운영 출처 확인 → 여행 시작.
- 검증된 6곳 중 확정 태그와 겹치는 후보를 우선순위 상위 4곳으로 제한하고, 최대 3곳의 방문 순서를 비교한다. 취향 태그 충족 범위, 중요 요소, 제목의 태그 키워드, 종료 시각과 이동 시간으로 선택한다. 모든 장소를 대상으로 한 최적 경로 보장은 아니다.
- 자유 설명은 전체 500자를 보존하지만 문장 속 모든 조건을 자동 해석하지는 않는다. 화면의 확인 사항에 한계를 표시한다. 이번 시간표에서 충족하지 못한 태그도 별도 안내한다.
- 선택 장소 도착 시각부터 계획한다. 출발지까지의 이동은 포함하지 않는다. 도보·대중교통은 마지막 장소에서 종료, 자동차는 장소별 이동·주차 후 출발지 복귀까지 포함한다. 실제 주차 위치를 임의로 지정하지 않는다.
- 이동·대기·촬영 체류·자동차 복귀 합계를 예산 이내로 강제한다. 날짜는 현재 이후 1년 이내, 자정 이전 종료로 제한한다.

## 시간·운영·경로

- SunCalc 2.0.2 getTimes로 장소 좌표/방문 날짜의 일출·일몰을 계산. 한국 시간은 UTC+09:00로 명시. 참고: https://github.com/mourner/suncalc 및 설치 패키지 index.d.ts.
- 노을 태그가 일치하는 곳은 일몰 40분 전~15분 후, 야경은 일몰 15분 후부터 배치한다. 일반 야외 촬영은 밝은 시간에 배치한다. 기상/지형에 따른 차이 안내, 날씨 예보 미조회.
- 실내 두 곳의 계절 운영시간, 보수적인 종료 1시간 전 입장 마감, 월요일/1월 1일 제외. 공휴일 대체 휴관·설날·추석·임시 휴관은 자동 조회하지 않으므로 현장 운영 확인 필요. 예술발전소 입장 마감은 공식 문구가 모호하여 1시간 여유로 계획한다.
- 도보: 기존 Tmap. 실패/키 누락 시 직선거리 × 1.4 ÷ 분당 60m 추정치 명시.
- 자동차: 기존 Naver 경로 조회 + 이동 구간당 주차/승하차 계획 여유 10분. 실패 시 임의 자동차 시간을 만들지 않는다.
- 대중교통: 기존 Transitous 조회. 현재 조회 시점의 참고값이며 방문일/각 방문 후 출발 시각의 배차를 반영하지 못한다. 이를 화면에서 명시. 조회 실패 시 임의 배차를 만들지 않는다.
- 경로 요청은 동일 방향 구간당 한 번으로 캐시하며 후보/순서 탐색을 제한한다. 신뢰할 수 없는 시간은 후보에서 제외한다.

## 확정·저장 및 다음 단계

- 생성 자체는 진행 중 여행을 변경하지 않는다. 사용자 확인 체크 후 기존 start 함수를 사용하며 진행 중 여행 덮어쓰기는 막는다.
- 취향 변경은 코스 편집기를 재생성한다. 제목/날짜/시간/이동수단/출발지 변경은 제안·확인을 지우고 진행 중 요청을 취소한다. 늦은 응답은 폐기한다.
- 응답 입력 스냅샷, 시간표 합계/순서/중복, 제안 15분 만료, 실제 시작 시각을 검사한다. 여행 시작은 방문 당일 계획 시각 전후 15분 이내로 제한한다. 미래 날짜 코스는 미리보기만 제공하며 방문 당일 다시 생성해야 한다.
- ActiveTrip v1 호환 선택 필드 photoTaste(tags/focus/note), photoPlan(date/startTime/originName), TripStop.photoGuide(tips/notice/plannedTime) 추가. 500자 설명을 잘라내지 않는다.
- 기존 photoPreferences는 태그로 유지. 재추천 공급자에게 전체 photoTaste를 추가 전달한다. 초기 촬영 시각은 진행 패널에서 '최초 계획'으로 표시하고 일정 변경 후 재확인을 안내한다.
- 여행 시작 후 위치/사진 입력과 기존 주차 복귀 재추천 기능 사용 가능. 13단계에서는 포토 코스 → 실제 주차 저장 → 현장 변경 → 취향/복귀 조건 유지의 통합 시나리오를 별도 검증한다.
