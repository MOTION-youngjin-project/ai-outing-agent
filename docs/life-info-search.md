# 장소 생활정보 검색

장소 상세 화면에서 사용자가 요청할 때만 네이버 웹문서 검색을 1회 실행해 주차·셔틀·휴무·예약·반려동물 정보를 찾는다. 추천 생성 단계에서는 호출하지 않는다.

## 비용 제한

- 장소와 주제별 결과를 DB에 7일 저장하고 모든 사용자가 공유한다.
- `최신 정보 다시 확인`도 마지막 수집 후 1시간 동안은 캐시를 반환하며, 같은 장소의 동시 요청은 외부 호출 한 번으로 합친다.
- 검색 결과는 상위 5개만 사용한다.
- 키워드가 명확하면 일반 코드로 추출한다.
- 정보가 없거나 한 문서에 여러 주제가 섞여 있을 때만 Gemini를 최대 1회 호출한다.
- AI 입력은 제목과 240자 이내 검색 요약만 사용하며 6초 후 중단한다.
- 외부 검색 실패 시 만료된 캐시가 있으면 그 결과를 표시한다.

## 환경변수

`NAVER_SEARCH_CLIENT_ID`와 `NAVER_SEARCH_CLIENT_SECRET`에 네이버 개발자센터 검색 API 키를 넣는다. `GEMINI_API_KEY`가 비어 있으면 AI 추출을 건너뛰고 규칙 추출 결과만 제공한다.

## 신뢰도

정부·공공기관·학교 도메인은 `공식 확인`, AI가 여러 검색 요약에서 추출한 정보는 `참고`, 그 외 단일 검색 결과는 `방문 전 확인`으로 표시한다. 원문 링크와 확인일을 항상 함께 제공하고 원문에서 게시일을 찾지 못하면 `게시일 확인 필요`로 표시한다.
