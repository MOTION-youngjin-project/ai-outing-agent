# 장소 유형별 주변 추천

- 관광지·미술관 등에서는 식당, 카페, 소품점을 서브 장소로 보여준다.
- 음식점에서는 기본 탭을 `식사 후 산책`으로 바꾸고 공원·산책로 후보와 근처 카페를 보여준다.
- 음식점 화면에는 `바로 귀가` 선택을 제공하며 누르면 주변 추천을 접는다.
- 카카오 카테고리의 음식점 분류로 메인 장소 유형을 판별한다.
- 공원·산책로·수목원·둘레길·강변·수변·호수·광장·숲길·유원지 후보만 남긴다.
- 후보는 가까운 순으로 최대 3곳 표시하며 직선거리와 분당 80m 기준 예상 도보시간을 함께 표시한다.
- 검색은 패널을 열고 탭을 선택했을 때만 실행되며 서버·클라이언트에서 30분 캐시한다. AI 호출은 없다.
- 카카오 로컬 API에는 실시간 영업 상태가 없으므로 운영시간을 확인하도록 지도 원문 링크와 안내를 표시한다.
